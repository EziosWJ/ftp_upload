# ADR-0001: 上传配置独立存储

## 状态

已采纳

## 背景

系统需要新增「上传配置」功能，允许用户配置定时报文生成任务、选择数据项目、管理寄存器测点。需要决定配置数据存储在哪里。

## 决策

使用独立的 `UploadConfig` 模型，存储在单独的 `upload_config.json` 文件中，不合并到现有的 `AppConfig`（`config.json`）。

## 理由

1. **关注点分离**：`AppConfig` 管理设备连接和采集调度，`UploadConfig` 管理报文生成配置，职责不同
2. **避免污染**：上传配置独立存储，不会让 `config.json` 变得臃肿
3. **独立持久化**：修改上传配置不需要重新加载整个 AppConfig，减少意外副作用

## 后果

- 需要新增 `upload_config.json` 文件和对应的加载/保存逻辑
- 上传配置的 API 端点独立于现有设备配置 API
